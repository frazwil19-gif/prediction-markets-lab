# Mobile Workflow

**Status: planned for Stage 2. Not yet implemented.**

This project must be operable primarily from a phone. This document
will describe, once Stage 2 is built:

- How to open and use the Google Sheets workbook on a phone
- How to paste bookmaker/exchange prices into ChatGPT on a phone
- How to interpret ChatGPT's graded output on a small screen
- How to record a placed bet back into Google Sheets from a phone
- How to check for the daily report without a desktop session

None of this depends on running Python locally on a daily basis. Any
Python execution (this repository's calculation engine) is intended to
be invoked occasionally in a development/maintenance session, or
wrapped by ChatGPT for daily use — not run by the user directly on
their phone.
