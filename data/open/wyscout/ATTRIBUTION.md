# Wyscout public soccer dataset — attribution (CC BY 4.0)

Derived from: Pappalardo, L., Cintia, P., Rossi, A. et al. A public data set of spatio-temporal match events in soccer competitions. Scientific Data 6, 236 (2019). https://doi.org/10.1038/s41597-019-0247-7 — data on figshare (collection 4415000), licensed CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).

Changes: events aggregated to player-match shots / shots on target / goals; minutes derived from lineups, bench and substitutions (red cards not modelled) by scripts/wyscout_player_match.py.
